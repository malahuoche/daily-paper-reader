## 摘要
跨视图物体地理定位（CVOGL）旨在将查询图像中感兴趣的物体定位在相应的卫星图像中。现有方法通常假设查询图像仅包含单个物体，这与现实应用中复杂的多物体地理定位需求不符，使其不适用于实际场景。为了弥合现实设置与现有任务之间的差距，我们提出了一个新任务，称为跨视图多物体地理定位（CVMOGL）。为了推进 CVMOGL 任务，我们首先构建了一个基准测试 CMLocation，其中包括两个数据集：CMLocation-V1 和 CMLocation-V2。此外，我们提出了一种新颖的跨视图多物体地理定位方法 MOGeo，并将其与现有的最先进方法进行了基准对比。在各种应用场景下进行了广泛的实验，以验证我们方法的有效性。结果表明，在更现实的设置下，跨视图物体地理定位仍然是一个具有挑战性的问题，鼓励在该领域进行进一步研究。

## Abstract
Cross-View Object Geo-Localization (CVOGL) aims to locate an object of interest in a query image within a corresponding satellite image. Existing methods typically assume that the query image contains only a single object, which does not align with the complex, multi-object geo-localization requirements in real-world applications, making them unsuitable for practical scenarios. To bridge the gap between the realistic setting and existing task, we propose a new task, called Cross-View Multi-Object Geo-Localization (CVMOGL). To advance the CVMOGL task, we first construct a benchmark, CMLocation, which includes two datasets: CMLocation-V1 and CMLocation-V2. Furthermore, we propose a novel cross-view multi-object geo-localization method, MOGeo, and benchmark it against existing state-of-the-art methods. Extensive experiments are conducted under various application scenarios to validate the effectiveness of our method. The results demonstrate that cross-view object geo-localization in the more realistic setting remains a challenging problem, encouraging further research in this area.

### 2. 方法论：MOGeo 框架
MOGeo 是一个端到端的检测框架，主要包含以下核心组件：
*   **双分支特征提取**：使用 ResNet18 提取查询图像特征，使用 Darknet53 提取参考（卫星）图像特征。
*   **多目标位置编码（MOPE）**：
    *   **核心思想**：受狄拉克δ函数启发，采用“脉冲式”编码而非传统的平滑高斯编码。
    *   **技术细节**：为每个查询点生成一个 One-hot 掩码，通过通道拼接和 $1 \times 1$ 卷积与视觉特征融合，再通过元素级乘法增强位置信息，从而产生高度判别性的空间先验，避免注意力图过于弥散。
*   **跨视图多特征融合（CVMF）**：
    *   将查询物体向量与卫星图像特征进行矩阵乘法，生成跨视图注意力图。
    *   利用注意力图对卫星特征进行加权集成，强化目标区域的特征表达。
*   **优化目标（损失函数）**：
    *   由置信度损失（$L_{cn}$）、回归损失（$L_{reg}$）和**相似性损失（$L_s$）**组成。
    *   $L_s$ 专门用于增大不同物体注意力分布之间的差异，提升模型在密集场景下的区分能力。

### 3. 实验设计
*   **基准数据集（CMLocation）**：

    *   **CMLocation-V2**：在 V1 基础上进行随机裁剪、翻转和缩放，模拟非中心对齐和非北向对齐的真实复杂场景。
*   **对比方法**：
    *   检索类方法：FRGeo, GeoDTR+, Sample4Geo 等。

    *   进行了针对不同物体数量（N≤3, 3<N≤6, N>6）的分组鲁棒性实验。

### 6. 主要结论与发现
*   **性能领先**：MOGeo 在 CMLocation-V1/V2 上均显著超越了现有方法，尤其在 accI@0.25 指标上提升明显。
*   **任务难度**：随着查询图像中物体数量的增加，所有模型的性能均有所下降，但 MOGeo 的下降幅度最小，表现出更强的鲁棒性。
*   **编码关键性**：消融实验证明 MOPE（脉冲式位置编码）对性能贡献最大，证明了精确的空间先验在多目标任务中的核心作用。

### 7. 优点与亮点
*   **任务前瞻性**：首次正式定义并探讨了跨视图多物体地理定位任务，更贴近自动驾驶和城市管理的实际需求。
*   **编码创新**：提出的脉冲式位置编码（MOPE）有效解决了跨视图匹配中注意力弥散的问题，提升了定位精度。
*   **基准贡献**：发布的 CMLocation 数据集填补了该领域多目标标注数据的空白。

### 8. 不足与局限
*   **图像级精度瓶颈**：尽管在物体级表现优秀，但在 accI（全图物体全对）指标上仍有较大提升空间，说明在极端复杂场景下仍存在漏检或误检。
*   **偏差风险**：数据集主要基于城市建筑场景，对于自然景观或纹理极度重复的区域（如森林、沙漠）的适用性尚未得到充分验证。
*   **应用限制**：模型依赖于查询图像中的“点击点”作为输入先验，在完全自动化的端到端流程中（即不提供点击点，自动识别并定位所有物体）仍需进一步探索。
